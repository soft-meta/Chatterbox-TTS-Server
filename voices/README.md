# Predefined voices

This directory contains reusable reference audio for the **Predefined Voices** selector.

SoftMeta v0.6.0 includes five user-provided WAV references:

- SoftMeta American Male Voice 01
- SoftMeta American Male Voice 02
- SoftMeta American Male Voice 03
- SoftMeta American Male Voice 04
- SoftMeta American Male Voice 05

Only add voice recordings that you own or have permission to use. A sidecar JSON file can define `name`, `gender`, and `accent` for a cleaner UI label.
