Tips & Tricks

  • For long scripts, keep Split text into chunks enabled.
  • Use a clean 10–20 second single-speaker reference for voice cloning.
  • For a natural American delivery, use an American-accent reference recording.
  • Audio jobs run one at a time so the GPU remains stable.
